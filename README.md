# Starter Praktik SSR Next.js | Kelompok 2

Project awal untuk jobsheet praktik **Server-Side Rendering (SSR)**.
Project ini sudah bisa dijalankan, tetapi halaman `/ssr-siswa` dan `/ssr-siswa/[id]` masih harus Anda lengkapi.

## Memulai

```bash
git clone <URL-REPOSITORY-STARTER>
cd ssr-starter
npm install
npm run dev        # buka http://localhost:3000
```

Persyaratan: Node.js 20 LTS atau lebih baru.

## Yang perlu Anda kerjakan

Cari komentar `TODO` di:

- `src/app/ssr-siswa/page.js` (Tugas 1 dan 4)
- `src/app/ssr-siswa/[id]/page.js` (Tugas 3)

Ikuti langkah di **Jobsheet SSR**. Halaman `/ssr-profil`, `/csr-siswa`, dan `/ssg-siswa` sudah lengkap sebagai bahan pengamatan dan perbandingan.
